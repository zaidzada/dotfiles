  TMUX KEYS                          prefix = ;

  Windows                            Panes
  c   new window (here)              |   split right
  a   new window after current       \   split right (full height)
  j/k next / prev window             -   split down
  L   last window                    _   split down (full width)
  l   last pane (or window)          o/h next / prev pane
  R   renumber windows               z   zoom toggle
  f   find window                    b   break pane to window
  <   window menu                    B   break pane (stay)
  >   pane menu                      J   join pane into...
                                     { } swap pane up / down
                                     ␣   next layout
                                     K   kill pane

  Copy                               Session
  [   copy mode                      s   switch session
  ]   paste                          S   session tree
  C-r search up                      D   detach
  C-s search down                    Q   kill session
                                     r   reload config
  Misc                               :   command prompt
  M   toggle mouse                   ;   send literal ;
  e   open sidebar
  C-l clear screen + history         Nesting (no prefix)
  M-c pick accent colour             M-S toggle outer tmux off/on

  ?   this help (q to close)
